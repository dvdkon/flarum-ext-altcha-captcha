# Altcha CAPTCHA

[![License: MIT](https://img.shields.io/badge/license-MIT-blue.svg)](LICENSE)

Self-hosted CAPTCHA extension for [Flarum](https://flarum.org) using [Altcha](https://altcha.org) — a modern, privacy-focused, proof-of-work CAPTCHA alternative. No image puzzles, no third-party tracking, no external service to run.

Based on [Ralkage's Cap extension](https://github.com/Ralkage/flarum-ext-cap-captcha).

## How It Works

Altcha uses SHA-256 proof-of-work instead of visual puzzles. When a user clicks the checkbox, their browser performs a computational challenge in the background. No images to identify, no data sent to third parties.

- Fully self-contained — challenges are generated by your own Flarum installation (no separate server needed)
- Privacy-first, GDPR compliant, WCAG accessible
- No API keys from a third party; only a local HMAC secret you choose

## Features

- **Registration protection** — Altcha widget on the sign-up form (enabled by default)
- **Login protection** — Optional Altcha widget on the login form
- **Server-side verification** — Payloads verified locally with the official [Altcha PHP library](https://github.com/altcha-org/altcha-lib-php)
- **Admin settings** — Configure the HMAC secret, proof-of-work cost, expiry, and which forms to protect
- **Privacy-first** — No telemetry, no tracking, fully self-hosted
- **Replay protection** — Each challenge can only be verified once; used challenges are tracked in Flarum's cache and rejected on reuse (until the challenge expires)

## Installation

Enable the extension in the admin panel under **Extensions > Altcha CAPTCHA**.

## Configuration

In the extension settings, set an **HMAC Secret** — any long random string (for example the output of `openssl rand -hex 32`). This secret signs every challenge and must stay private. The proof-of-work **Cost** and challenge **Expiry** can also be tuned.

| Setting | Description |
|---|---|
| **HMAC Secret** | A random secret used to sign challenges. Keep it private. |
| **Proof-of-work cost** | Number of iterations (higher = harder for bots). Default: 20000. |
| **Challenge expiry (seconds)** | How long a challenge stays valid. Default: 300. |
| **Require CAPTCHA on registration** | Show widget on sign-up form (default: on) |
| **Require CAPTCHA on login** | Show widget on login form (default: off) |

No external server, API endpoint, or site key is required — the extension serves challenges from its own `/altcha-challenge` route.

## Requirements

- Flarum `^1.8`
- PHP 8.0+
- The [`altcha-org/altcha`](https://github.com/altcha-org/altcha-lib-php) PHP library (installed automatically via Composer)
